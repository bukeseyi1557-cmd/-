# 小伙伴桌宠 6.0（数据守护版）

6.0 的重点是在日常陪伴基础上增加可靠的数据备份与恢复，让长期养成和共同回忆更安心。此前版本的心情日记、专注计时、聊天记录与朋友养成仍然保留。

5.0 的重点是让桌宠不只是在桌面上出现，而是能支持你的日常：记录心情、陪你专注、保留共同聊天的上下文，同时把数据控制权留在用户手中。

## 本次新增

### 1. 桌宠数据备份与恢复
- 可导出好感度、昵称、主题、性格、星星币、回忆、聊天记录和心情日记等本地数据。
- 可将备份内容保存到文件、笔记或个人云盘，再通过粘贴完整 JSON 恢复。
- 恢复前有二次确认，明确提示会覆盖当前本地数据。
- API Key 不会写入备份文件。


### 1. 日常陪伴小屋
- 记录 5 档心情，可选写下当天发生的事。
- 心情记录保存在本机，最多展示最近 30 条。
- 可以查看最近心情记录，也可二次确认后清空。
- 她会根据心情选择不同的回应：低落时先倾听，开心时一起庆祝。

### 2. 专注陪伴计时
- 25 分钟专注计时、5 分钟休息计时。
- 支持暂停、继续和手动结束。
- 完成专注会奖励 2 枚星星币和少量好感，并累计专注次数。
- 计时页面离开前台会暂停，避免后台计时造成误会。

### 3. 本地聊天记录
- 桌面悬浮聊天和完整聊天页共享最近聊天记录。
- 关闭并重新打开聊天页面后，可以看到最近 36 条对话。
- 本地保存最多 120 条消息。
- 朋友档案可查看最近 40 条记录，并可二次确认后清空。
- 独立 AI 模式会将当前 API 会话中新发送的消息及其上下文发送到用户配置的服务商；之前保存的聊天记录不会自动作为上下文发送。
- 切换聊天模式时会清空当前会话上下文，避免把之前本地模式的对话意外带入 AI 请求。

### 4. 成就与稳定性
- 新增“专注搭档”和“心情记录员”成就。
- 修正 AI 请求历史中当前用户消息重复拼接的问题。
- 增加聊天记录与心情日记的本地管理入口。

## 继续保留的功能

- Android 桌面悬浮宠物，单击互动、双击桌面对话、长按菜单、拖动移动。
- 4 套主题与 3 种性格。
- 好感度、关系称号、心情、精力、饥饿感、连续陪伴天数。
- 每日签到、小目标、每日惊喜、星星币、投喂、礼物、专属昵称、回忆本与成就徽章。
- 免费本地陪聊、ChatGPT 网页入口、兼容 OpenAI Chat Completions 的独立 AI 接口。

## 隐私说明

- 心情日记、聊天记录和回忆本默认保存在设备本地。
- 本地聊天模式不联网。
- 使用独立 AI 模式时，当前 API 会话中发送的消息及上下文会发送给你配置的 AI 服务商；之前保存的本地聊天记录不会自动发送。不要在聊天中输入密码、支付信息等敏感内容。
- 清空聊天记录不会清空回忆本、好感度或心情日记。
